# 소식글 구조

당근에서 **구매 직전 고객이 읽는 글**을 쓰는 규칙. 무엇을 팔지는 [[소싱-기준]], 광고로 데려오는 건 [[당근광고-실측]], 인스타 유입은 [[인스타-컨셉-평가기준]].

> **이 노트가 지금 vault 최우선인 이유**: [[당근광고-실측]] 기준 CTR 3.19%는 정상인데 구매전환율이 **1.28%**다. 클릭 1,098건 중 14건만 샀다. 광고가 아니라 이 글이 병목이다.

## 1. 당근 소식글의 전제 (네이버·쿠팡과 다름)

| 네이버·쿠팡 | 당근 |
|---|---|
| 필요해서 검색하고 들어옴. 글을 안 읽어도 됨 | **살 생각 없는데** 광고를 우연히 클릭해 들어옴 |
| 인포그래픽·큰 문구만 훑음 | **글을 꼭 다 읽게 만들어야 함** |

구매 결정까지 **10~20초.** 우연히 클릭 → 문구에서 기대 → 초반 1~2초 판단 → 내리면서 호기심 증폭.

## 2. 두 가지 구조 — 상품 유형이 먼저다

유형 판별은 [[소싱-기준]] §3. 질병·문제 해결이면 결핍형, 매일 먹는 가공식품이면 충동형.

### 결핍형 5단계
```
문제 인식 → 착각 깨기 → 해결 방향·기준 제시 → 검증/후기 → 구매
```
- **초반**: 결핍을 건드려 '내 얘기다' + 기존 솔루션 소용없었다는 공감
- **중반**: 원인을 재해석해 기존 실패를 납득시킴
- **후반**: 해결 가능성 + 사례 + 신뢰
- 핵심은 정보 제공이 아니라 **기존 실패 경험을 뒤집는 것**

전제: 결핍 있는 사람은 이미 좋은 재료를 안다. 안 산 이유는 ① 구매 동기 없음 ② 효과 불신 ③ 너무 비쌈. 따라서 **"상품 접근성"과 "구매 동기"** 두 개만 주면 산다.

### 충동형 3단계
```
흥행성/이상함 → 상품 욕구 증가 → 지금 사야 할 이유
```
- 초반부터 설명하면 망한다. **2~3줄 안에 강한 호기심(때로는 이상함)**
- 마지막은 "저장"이 아니라 **지금** 사게 만드는 장치 (한정·가격 인상 예고 등)

## 3. 문장 규칙 (전부 강제)

| 규칙 | ✕ | ○ |
|---|---|---|
| 타겟은 좁게 | "건강으로 고민하시는 분들" | "고지혈증에 특히 좋다" |
| 쉬운 말 | "퀘르세틴 성분이 2배" | 읽기 쉬운 설명 |
| 암시, 확정 금지 | "우리 제품이 1등이에요" | 독자가 스스로 느끼게 |
| 맛은 긍정어 | "쓰지 않아요" | "달다, 시다" |
| 약점을 가치로 | (배송 느림을 숨김) | "당일 생산 후 출고라 2~3일 걸립니다" |

**카피 3요소**를 초반에 심는다 — 전문성(30년 출신) · 구체성(제주쑥을 인천에서) · 흥행성(단골 47,000분).
내 서사를 시간순으로 늘어놓지 말고 **상품 이야기에 곁들인다.** 길수록 어필하는 티가 나므로 짧게.

## 4. 소식글 : 후기 = 50 : 50

소식글은 판매자의 주장, 후기는 고객의 증언. **양쪽을 다 들어야 산다.**
네이버·쿠팡에서 후기는 형식적이지만, **당근은 판매자 검증이 없어 후기가 마지막 결정타**다.
단 소식글을 다 읽고 "구매 고려" 단계까지 가야 비로소 후기를 읽는다 — 순서가 있다.

기준: 단골 최소 50개(가능하면 100개), 후기 최소 10개. **비즈프로필 자체의 완성도가 더 중요**하다.
후기를 20개 이상 채울 경우 앞의 12개 정도만 양 채우기용이고, **최상단 후기는 반드시 직접 작성**한다.

## 5. 댓글과 CS

- 댓글은 소식글에 바로 보인다(후기는 비즈프로필에 보임). 성실히 달면 채팅 문의로 이어진다
- "채팅 주세요" 식 댓글 말고, **댓글 자체가 정보성 콘텐츠**가 되게 쓴다
- **CS 원칙: 불만족 시 즉시 환불.** 나쁜 후기를 남길 것 같은 고객은 환불하거나 서비스를 더 보낸다. 작은 리스크가 큰 손실을 부른다

## 6. 첨삭에서 반복된 지적

- "완판됐다" → 구체적인 사진이 있어야 믿는다
- "제 글을 공감해 주시고 꾸준히 주문해 주십니다" → **보여주기용 문장으로 읽혀 신뢰가 깎인다**
- "80박스 나가서 며칠 보낼 게 없어요" → 자랑조로 쓰지 말고, 못 보내 미안하다는 식으로 **돌려 말하며 암시**할 것
- 후기가 오래됐으면 하루 2~5개씩 계속 쌓을 것

## 데이터 갭

- 전환율 1.28%는 **소식글 개선 전** 수치다. 개선 후 재측정해야 효과를 안다
- 현재 운영 중인 소식글 원문이 vault에 없다 — 첨삭하려면 실물이 필요
- 결핍형 실적이 없다. 취급 상품(된장·게장)이 전부 충동형이라 결핍형 5단계는 미검증
