# 비즈프로필 세팅

당근마켓에서 **내 가게**를 만들고 유지하는 규칙. 계정 구조·인증·규제까지.
그 안에 들어가는 글은 [[소식글-구조]], 팔 물건은 [[소싱-기준]], 인스타 연결은 [[인스타-컨셉-평가기준]]. vault 규칙은 [[raw-wiki-규칙]].

## 1. 계정 구조 — 비즈프로필과 광고 계정은 별개다

```
당근마켓 계정 (나 자신)
├── 비즈프로필 (내 가게)  — 전화번호당 1개
└── 광고 계정            — 별도 계정. 나중에 연결 필요
```

| | 비즈프로필 계정 | 광고 계정 |
|---|---|---|
| 통신판매업 면허 | **불필요** | **필수** |
| 생성 시점 | 먼저 | 나중에 만들어도 됨 |
| 관리자 추가 | 가능 | 가능 |

- 사업자 1개로 비즈프로필 인증을 계속 할 수 있다
- 비즈프로필 이름은 변경 가능하나, **변경할 때마다 사업자·명함 등으로 재인증**해야 한다

> ⚠️ **원본 모순**: [[2주차강의자료]] 슬라이드 7이 "번호 3개면 비즈프로필 총 15개"와 "번호 3개면 계정 3개·비즈프로필 9개"를 같은 장에서 함께 말한다. 실제 상한은 **당근 정책 직접 확인 필요**. 계정을 늘릴 계획이 생기면 그때 검증할 것.

## 2. 네이밍 — 기억에 남게

| 평범 | 개선 |
|---|---|
| 정직한 방앗간 | **20년전통풍산떡집** |
| 청년약방 | **숭의동탈모전문약방** |
| 심리상담센터 | **7년간8억투자한심리센터** |

업종 선택은 ① 사업자등록증 [종목] ② 업체 대표 단어 ③ 제공 서비스 순으로 검색.
이름 자체가 마케팅 포인트가 되므로 [[소식글-구조]]의 카피 3요소(전문성·구체성·흥행성)를 이름에도 적용한다.

## 3. 프로필 완성도

**웬만하면 빈 칸 없이 전부 채운다.**

| 항목 | 규칙 |
|---|---|
| 주소 | 집으로 사업자 등록했으면 **반드시 '주소가 없어요' 체크.** 추후 수정 불가(사업자 주소지를 바꿔야만 가능) |
| 사진 | 귀엽고 상업적인 로고보다 **상품 관련 진정성 있는 이미지** |
| 공지 | 관심 끌 문구 (할인·무료배송·특가·1+1) |
| 소개 | 페르소나 + 제작자 가치관이 드러나게, **100자 이내** |
| 영업시간 | 빈 칸 없이. 정기 휴무도 표기 |

### 실제 운영 화면에서 확인되는 구성 (효자장연구소 사례)
탭은 **홈 / 소식 / 사진 / 후기** 4개. 그 외 세팅 가능한 것:

- **부가 정보** — 예약·포장·지역화폐 등
- **안심 번호** 지원 (실번호 비노출)
- **홈페이지/SNS 링크 — 최대 5개** ← 인스타→당근 역방향 동선에 직결. [[인스타-컨셉-평가기준]] 참조
- **단골 혜택** 등록 시 비즈프로필 홈과 **소식 양쪽에 노출**
- **"1일 이내 활동" 배지** — 응답 속도가 노출됨

실제 운영 문구 예시(공지): `"1+1", 1~4번세트 중 마음에 드시는 걸로 말씀주세요 📞`

## 4. 증빙 자료 제출

- **실물 명함이 가장 잘 통과**한다. 안 되면 간판으로 인증
- **AI로 만든 명함은 반려**된다. 간판은 잘 만들면 통과
- AI·이미지로 만들더라도 **반드시 프린터로 출력해 사진을 찍어** 제출할 것

## 5. 규제 — 미리 해둬야 하는 신고

| 상황 | 필요한 것 |
|---|---|
| 축산물 판매 | **축산물유통전문판매업 영업신고 필수** (다른 업종은 현재 규제 없음) |
| 전문가계정으로 광고 집행 | **통신판매업 신고 필수** |

통신판매업 신고는 『전자상거래법』상 **'사업자등록 여부'가 핵심**이고, 사업자등록증의 업종 코드 일치는 필수 요건이 아니다. 기존 등록증에 통신판매 관련 업종이 없어도 지자체(시·군·구청)에 별도 신고할 수 있다.

## 6. 착수 순서

1. 비즈프로필 계정 생성 → 인증(실물 명함)
2. 프로필 전 항목 채우기 (주소 체크 주의)
3. 통신판매업 신고 — **광고 집행 전에 미리**
4. 광고 계정 생성 및 연결
5. 소식글 작성 → [[소식글-구조]]
