# 당근광고 실측 (민속된장, 2025-09-25 ~ 10-07)

당근 피드광고 11일 집행 실측치. **결론: 이 광고는 켤수록 손해였다.**
마진 기준은 [[소싱-기준]], 전환 병목의 원인은 [[소식글-구조]](미작성), vault 규칙은 [[raw-wiki-규칙]].

## 1. 집행 총계

| 지표 | 값 |
|---|---|
| 기간 | 2025-09-25(목) ~ 10-07(화) — 13일 중 **집행 11일** (토·일 2일 0원) |
| 총 광고비 | **156,721원** |
| 총 노출 | 34,395 |
| 총 클릭 | 1,098 |
| 총 구매 | **14건** |
| 평균 CTR | **3.19%** (일별 2.66~4.51%) |
| 구매전환율 | **1.28%** (일별 0~3.64%) |
| CPC | 143원 |
| **CPA (구매 1건당 광고비)** | **11,194원** |

## 2. 핵심 판정 — CPA가 마진보다 크다

| 상품 | 마진액 | CPA 차감 후 | 판정 |
|---|---|---|---|
| 민속된장 (실제 광고 대상) | 2,400 | **−8,794** | 팔수록 손실 |
| 순애할매 | 5,700 | −5,494 | 손실 |
| 오디즙 | 9,300 | −1,894 | 손실 |
| 양파즙 | 13,000 | +1,806 | 겨우 흑자 |

**유료광고 최저 마진선 = 11,194원.** [[소싱-기준]]의 소싱 6건 중 이 선을 넘는 건 양파즙 1건뿐이고 그마저 건당 1,806원이라, **유료광고로 규모를 키우는 전략은 현재 상품군에서 성립하지 않는다.**

> 양배추즙(13,100원)은 택배비·구매전환비 공란으로 과대 계상 의심 상태라 위 표에서 제외했다 ([[소싱-기준]] 데이터 갭 참조).

## 3. 병목은 광고가 아니라 소식글

- **CTR 3.19%는 정상 작동.** 노출→클릭 단계는 문제없음. 광고 소재·후킹 문구를 고칠 이유가 없다
- **전환율 1.28%가 병목.** 클릭 1,098건 중 구매 14건. 소식글이 구매까지 못 끌고 감
- → 개선 순서는 **광고 소재 ✕ / 소식글 전환율 ○**. [[소식글-구조]] 작성이 광고 재개보다 먼저다

## 4. 운영상 발견

- **구매 0건이 3일 연속**(10-01~10-03)인데 광고비 31,310원이 그대로 나갔다. 손절 룰이 없었음
- 주말 2일 집행 0원 — 의도적 중단인지 예산 소진인지 기록 없음
- 같은 기간 발주 실적은 18건([[00_십채-인덱스]]), 광고 귀속은 14건. 차이 4건은 광고 외 경로(단골·검색·인스타)로 **추정**. 발주일과 구매일이 달라 정확한 귀속은 불가

## 5. 다음 집행 판단 기준

1. **재개 조건**: 해당 상품 마진 > 11,194원 확인 후에만
2. **손절 룰**: 구매 0건 2일 연속 시 즉시 중단, 소식글부터 손볼 것
3. **대안 경로**: 마진이 CPA를 못 넘으면 유료광고 대신 오가닉 유입으로 전환 — [[인스타-컨셉-평가기준]]

## 데이터 갭

- 단일 상품·단일 기간 11일치뿐. 다른 상품·계절 데이터 없음
- 광고 클릭의 랜딩이 비즈프로필인지 소식글인지 구분 기록 없음
- 오가닉 유입의 실측 CPA 대안 수치 전무 — 인스타 계정 육성 시 이 값이 비교 기준이 된다
