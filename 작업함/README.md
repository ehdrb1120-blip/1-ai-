# 작업함 (staging)

에이전트가 만든 **초안**이 쌓이는 곳. `raw`도 `wiki`도 아니다.

| | raw/ | **작업함/** | wiki/ |
|---|---|---|---|
| 성격 | 불변 원천 | 에이전트 산출 초안 | 검증된 지식 |
| 누가 씀 | 사람 (외부 자료 반입) | 서브에이전트 | 사용자 승인 후 `/ingest` |
| 신뢰도 | 원본 그대로 | **미검증** | 검증됨 |
| 지워도 되나 | ✕ | ○ (언제든) | ✕ |

## 규칙

- 에이전트는 여기에만 쓴다. `wiki/`·`raw/`에는 쓰지 않는다.
- 여기 있는 건 전부 **초안**이다. 그대로 쓰지 말고 검토 후 `/ingest`로 wiki에 올리거나 버린다.
- 오래된 초안은 그냥 지우면 된다. 원천은 `raw/`에 남아 있다.

## 폴더

```
작업함/
├── 소싱/        sourcing-research 산출 — 후보 리서치, 마진 감시
├── 카피/        copy-draft 산출 — 소식글·상세페이지 초안
├── 인스타/      insta-plan 산출 — 게시물 기획, 해시태그
├── 진단/        vault-keeper 산출 — lint 리포트
└── ingest초안/  vault-keeper 산출 — wiki 반입 후보 초안
```

> 이 폴더는 `CLAUDE.md`의 3레이어에 포함되지 않는 **작업용 임시 공간**이다. 스키마에 정식 편입하려면 사용자 승인이 필요하다.
