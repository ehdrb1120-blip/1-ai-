# ✍️ 소식글 공식

[[당근마켓/00_당근마켓_대시보드]]

## 결핍기반형
문제인식 → 착각깨기 → 해결기준 → 검증/후기 → 구매

## 충동구매형
흥행성/이상함 → 욕구증가 → 지금 구매 이유

## 공통 원칙
- 초반 **2~3줄에 강한 후킹** 필수
- **20초 이내** 구매결정 유도
- 암시의 기술: 결론을 직접 말하지 말고 느끼게
- 카피 3요소: **전문성 + 구체성 + 흥행성**
- 타겟은 좁게, 톤은 자신감 + 따뜻함 + 유머
