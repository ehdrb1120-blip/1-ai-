# 시작 전 반드시 읽을 것
1. `CLAUDE.md` — vault 스키마
2. `wiki/sourcing/소싱-기준.md` — 판정 기준의 유일한 출처. 여기 없는 기준을 임의로 만들지 마라.
3. `raw/당근마켓/십채/마진계산기(250913).md` — 현재 소싱 6건 실측치

# 판정 기준 (소싱-기준 노트에서 가져옴, 임의 변경 금지)

**통과 4조건 — 전부 충족해야 후보**
- 월 검색량 1,000 이상 (아이템스카우트 기준)
- 실사용자의 "효과 있다" 후기 존재 (스토어·블로그·카페)
- 네이버에서 누적 1,000개 이상 판매 셀러 2곳 이상
- 목표 마진을 보존하는 최저가가 실재

**가격·마진**
- 마진액 = 판매가 − 공급가 − 택배비 − 구매전환비
- 목표 마진 10,000~15,000원
- 내 판매가는 네이버 1페이지 가격 대비 50% 이내
- 판매가 상한: 충동구매 38,000원 / 결핍 59,000원 (무료배송 기준)
- 판매가는 만원·천원 단위로 끊기 (19,500 / 24,900 / 29,000 / 36,000)

# 작업 절차

## A. 신규 후보 리서치 요청일 때
1. WebSearch로 해당 품목의 네이버 최저가·판매 셀러 수·후기 밀도를 조사
2. 4조건 각각에 **충족/미달/확인불가** 판정 + 근거 URL
3. 마진 시뮬레이션: 판매가 후보 2~3개 × 예상 공급가 → 마진액 계산
4. 최종 판정: **후보 채택 / 보류 / 탈락** 중 하나 + 한 줄 이유

### 웹으로 검증 불가능한 항목 처리 (중요)
실측 결과, 4조건 중 **월 검색량**과 **셀러 누적 판매량**은 웹 검색으로 거의 확인되지 않는다 (아이템스카우트는 로그인 필요, 네이버 판매량은 비공개). 이건 네 실패가 아니라 구조적 한계다.

- 이 두 항목은 억지로 추정하지 말고 **확인불가**로 두고, 리포트 맨 아래에 **"사용자 수동 확인 목록"**을 만들어라:
  - 아이템스카우트에서 볼 것: 월 검색량 / 경쟁강도 / 검색추이 / 연령대
  - 네이버 검색으로 볼 것: 1페이지 최저가(단위 정확히), 판매 1,000+ 셀러 수
- 웹으로 실제 확인 가능한 것에 집중해라: **판매 중인 가격대, 상품 구성(용량·포장), 후기 내용과 밀도, 공급처 후보 URL**
- "확인불가"가 절반 이상이면 최종 판정은 **보류**로 하고 채택/탈락을 억지로 내리지 마라

## B. 마진 감시 요청일 때
1. `마진계산기(250913).md` 마진계산기 시트를 읽고 전 건의 마진액을 기준과 대조
2. 미달 건마다 **판매가를 올릴지 / 공급가를 낮출지** 중 어느 쪽이 현실적인지 제시
3. 이미 알려진 미달 4건(민속된장 2,400 / 민속된장 타처 7,900 / 순애할매 5,700 / 오디즙 9,300)은 재보고하지 말고 **변화가 있을 때만** 언급
4. 알려진 미확정 건: **양배추즙(맛뜰무안)** 은 택배비·구매전환비 칸이 공란이라 마진 13,100원이 과대 계상돼 있다. 동일 공급처 양파즙 기준(구매전환비 5,000) 적용 시 8,100원으로 기준 미달로 뒤집힌다. 시트가 채워지기 전까지 **충족 건수에 넣지 마라**

# 출력 규칙
- 결과는 `작업함/소싱/{YYYY-MM-DD}-{품목}.md`에 쓴다
- 모든 수치에 출처 URL 또는 `(추정)` 표기. 근거 없는 숫자 금지
- 검색으로 확인 못 한 항목은 **"확인불가"**로 남긴다. 그럴듯하게 채우지 마라
- `wiki/`와 `raw/`에는 **절대 쓰지 않는다**. wiki 반영은 사용자가 `/ingest`로 결정한다
